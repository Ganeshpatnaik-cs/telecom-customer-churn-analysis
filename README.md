# telecom-customer-churn-analysis# Customer Churn Analysis and Prediction

**Business question:** Which telecom customers are most likely to leave, why, and what should the company do about it?

End-to-end analysis in Python: data cleaning, exploratory analysis, two prediction models, and a scored dataset ready for a Power BI / Tableau dashboard.

> **Data note:** The included `data/telco_churn.csv` is **synthetic**, generated by `data/generate_data.py` to match the schema of the public IBM *Telco Customer Churn* dataset (7,043 customers, 21 columns). The numbers below come from this synthetic data. To get real findings, download the real file from Kaggle, save it as `data/telco_churn.csv`, and re-run the script. No code changes are needed.

## Tech stack
Python, Pandas, NumPy, scikit-learn, Matplotlib. Dashboard layer: Power BI or Tableau.

## Method
1. **Cleaning:** converted `TotalCharges` to numeric (11 blank values, all brand-new customers, set to 0), checked duplicates (none), created a binary churn flag.
2. **EDA:** churn rate by contract, tenure band, internet service, payment method, support add-ons, and monthly charges.
3. **Modeling:** one-hot encoding plus scaling in a scikit-learn pipeline, 80/20 stratified split, class weights to handle the 27/73 imbalance. Compared Logistic Regression and Random Forest.
4. **Export:** scored every customer with a churn probability and a Low / Medium / High risk segment for the dashboard.

## Results (on the synthetic data)
Overall churn rate: **26.8%** (1,888 of 7,043 customers).

| Segment | Churn rate |
|---|---|
| Month-to-month contract | 43.1% |
| One-year contract | 12.2% |
| Two-year contract | 1.8% |
| Fiber optic internet | 39.7% |
| No internet service | 6.7% |
| Tenure 0-12 months | 50.0% |
| Tenure 49-72 months | 4.5% |
| Electronic check payers | 30.7% (vs about 25% for other methods) |

| Model | ROC-AUC | Churn recall | Churn precision |
|---|---|---|---|
| Logistic Regression | **0.871** | 84.4% | 57.5% |
| Random Forest | 0.862 | 81.0% | 56.5% |

Logistic Regression performed slightly better and is easier to explain, so it was used for scoring. It flagged 2,467 customers as high risk, and 59.1% of them actually churned.

Top churn drivers: month-to-month contract, fiber optic service, electronic check payment, and no online security or tech support. Longer tenure and two-year contracts reduce risk the most.

## Business recommendations
1. **Move month-to-month customers to longer contracts.** This group churns at roughly 24 times the rate of two-year customers. Offer a discount or bundled perk for a 12-month commitment.
2. **Focus retention on the first year.** Half of customers in their first 12 months churn, so add onboarding calls and a first-90-days check-in.
3. **Investigate fiber optic service quality and pricing.** It churns far more than DSL, which points to a pricing or reliability problem.
4. **Bundle tech support and online security** for at-risk customers, and nudge electronic check payers toward automatic payment.
5. **Use the risk scores.** Send the High-risk list to the retention team each month, starting with the highest-revenue customers.

## Limitations
- Results are from synthetic data, so the exact percentages will differ on the real dataset.
- The model is trained on a single snapshot, so it shows association, not proof of cause.
- Precision for churners is about 57%, so some retention offers would go to customers who would have stayed. Tune the 0.5 threshold against the cost of an offer versus the value of a saved customer.
